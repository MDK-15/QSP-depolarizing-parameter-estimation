# QSP-depolarizing-parameter-estimation
The goal of this work is to estimate decoherent noise parameters as efficiently as possible

We utilize the QSP framework to build circuits optimized to maximize sensitivity to the desired parameters. We use gradient ascent to find optimal parameters.
